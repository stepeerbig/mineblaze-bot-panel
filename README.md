# MineBlaze Bot Panel

Панель управления Minecraft-ботом на mineflayer (Minecraft 1.21.11) для Windows.

## Что умеет

- **Старт / Стоп** бота.
- **Экран бота**: отдельное окно, в котором видно, что делает бот (подробнее ниже).
- **Автоматический реконнект: OFF / ON** с паузой между попытками. После трёх неудачных попыток подряд пауза удваивается (не больше 60 с), чтобы не долбить лежащий сервер. При бане, отсутствии в белом списке, входе под этим ником с другого места и неподходящей версии реконнект не запускается: он бы не помог, а при входе с другого места выкинул бы тебя.
- **Консоль** — только статусы и ошибки: подключение, подключен, в сети, не в сети, кик (с причиной по-русски), не удалось подключиться, бот погиб / возродился, ресурспак. Одинаковые строки подряд сворачиваются в «×N».
- **Чат** — весь чат сервера с цветами (включая hex-градиенты в префиксах). Внизу строка для сообщений и команд: Enter — отправить, ↑/↓ — история.
- **Автовход и команды** (свёрнутый блок слева): пароль для `/login` и команды после входа, например `/server survival`. Отправляются один раз после появления в мире. Хранятся зашифрованными, в чате и логах пароль заменён точками.
- **Логи**: весь чат и консоль пишутся в файлы по дням, кнопка «Логи» открывает папку.
- Вход **Offline** или **Microsoft**: код сам копируется в буфер обмена, страница входа открывается в браузере.
- Повторный запуск программы открывает уже запущенное окно (два бота с одним ником выкидывали бы друг друга).

## Экран бота

Кнопка «Экран бота» под «Старт / Стоп» открывает отдельное окно с 3D-видом мира вокруг бота: блоки, другие игроки и мобы.

- Два режима, переключаются в самом окне и запоминаются. **Глазами бота**: камера смотрит туда же, куда бот. **Со стороны**: бот виден как игрок, камеру можно вращать мышью (левая кнопка), сдвигать (правая) и приближать колесом.
- Пока бот не в сети, окно так и пишет. Когда бот появится в мире (в том числе после реконнекта), картинка обновится сама.
- Работает на любой версии, на которой играет бот. Картинку рисует prismarine-viewer, а он знает блоки только до 1.21.4, поэтому блоки, появившиеся в 1.21.5 и позже, показываются похожими старыми блоками.
- Окно можно закрыть в любой момент, бот продолжит работать. F5 — перезагрузить картинку, F12 — инструменты разработчика.
- Картинка идёт через локальный сервер, доступный только с этого компьютера (127.0.0.1).

## Как получить .exe

1. Установи Node.js LTS: https://nodejs.org (нужен только для сборки).
2. Распакуй папку проекта куда угодно и дважды кликни `build-exe.bat`. Он ставит зависимости, прогоняет тесты и собирает exe.
3. Через несколько минут откроется папка `dist`, в ней `MineBlazeBotPanel.exe`. Это portable-программа: копируй куда хочешь и запускай, Node.js на этом ПК уже не нужен.

Сборка требует интернет: скачиваются Electron и зависимости.

### Готовый exe с GitHub (без сборки у себя)

После каждого изменения в ветке `main` GitHub сам прогоняет тесты и собирает exe (файл `.github/workflows/build.yml`).

- **Свежая сборка**: страница репозитория → вкладка **Actions** → верхний зелёный запуск «Сборка exe» → внизу в **Artifacts** файл `MineBlazeBotPanel.exe`. Хранится 14 дней. Скачивать можно, только войдя в GitHub.
- **Версия для раздачи**: поменяй `version` в `package.json` (например, на `1.2.0`), отправь изменения и поставь тег `v1.2.0`: `git tag v1.2.0` и `git push origin v1.2.0`. Через несколько минут exe появится на странице **Releases**. Если тег не совпадает с версией в `package.json`, сборка остановится с понятной ошибкой.
- Запустить сборку вручную: Actions → «Сборка exe» → **Run workflow**.

## Тестовый сервер (стенд)

Свой сервер Paper с античитом [GrimAC](https://modrinth.com/plugin/grimac) на этом же ПК. На нём бота проверяют без риска для аккаунта на настоящем сервере: Grim пишет, какая именно его проверка сработала.

- Нужна Java 21 или новее.
- `test-server\start-test-server.bat` — скачивает (или обновляет) Paper 1.21.11 и Grim, проверяет контрольные суммы и запускает сервер в этом окне. При первом запуске спросит согласие с [EULA Minecraft](https://aka.ms/MinecraftEULA). Другая версия: `start-test-server.bat -McVersion 1.21.4`; при переходе на более старую версию удали папку `test-server\server\world*`.
- Сервер доступен только с этого компьютера: в панели укажи адрес `localhost`. Вход без пароля, с любым ником. Остановить: напиши в окне сервера `stop`.
- `npm run stand:check` — автоматическая проверка: поднимает сервер (если он не запущен), заводит бота `StandBot` тем же кодом, что и панель, держит в мире 60 секунд (`npm run stand:check -- 300` — 300 секунд) и печатает итог: сработавшие проверки Grim, кики, жалобы сервера. Код выхода 0 — ничего не замечено.
- Сервер, мир и логи лежат в `test-server\server` (в git не попадают). Лог: `test-server\server\logs\latest.log`.

## Работа в VS Code

1. «Файл → Открыть папку» → папка проекта.
2. В терминале (Ctrl+`) один раз: `npm install`. Если потом `npm start` пишет, что Electron не найден, выполни `node node_modules/electron/install.js` (новые версии npm иногда не запускают скрипт, который скачивает Electron; батники делают это сами).
3. `npm start` — запустить панель, `npm test` — тесты (сеть и сервер не нужны).
4. F5 — запуск с отладчиком (конфигурация уже лежит в `.vscode/launch.json`).

Без VS Code: дважды кликни `start-dev.bat`.

## Где что лежит

- Настройки: `%APPDATA%\MineBlazeBotPanel\config.json`, логи: `%APPDATA%\MineBlazeBotPanel\logs`.
- `src/bot-manager.js` — запуск и остановка бота, реконнект, автовход, события.
- `src/main.js` — окно, настройки, логи, связь интерфейса с ботом.
- `src/renderer/` — внешний вид и логика окна (консоль, чат).
- `src/viewer/` — экран бота: локальный сервер картинки (`viewer-server.js`), перевод блоков новых версий в понятные prismarine-viewer (`block-translator.js`), исправления его готовых скриптов (`bundle-patches.js`) и страница окна (`page/`).
- `src/chat-utils.js` — перевод причин кика и ошибок в читаемый текст, скрытие паролей.
- `src/config.js` — настройки по умолчанию и их проверка.
- `test/logic.test.js` — тесты логики (подделка вместо настоящего бота).
- `test-server/` — тестовый стенд: установка сервера (`setup.ps1`), запуск (`start-test-server.bat`) и автоматическая проверка бота (`check.js`).
- `.github/workflows/build.yml` — сборка exe на GitHub и выпуск версий по тегу.

## Если что-то не так

- **«Не удалось запустить бота: ... version ... not supported»**: в папке проекта выполни `npm install mineflayer@latest` и собери заново. Версия 1.21.11 поддерживается начиная с mineflayer 4.35.
- **Бот заходит, но через 30–60 секунд его кикает за «время авторизации»**: на сервере вход по паролю. Впиши пароль в «Автовход и команды». Новый аккаунт один раз зарегистрируй сам через строку чата: `/register пароль пароль`.
- **Бот завис в статусе «Подключен» и не появляется в мире**: скорее всего, сервер проверяет игрока анти-бот защитой (капча, проверка падением). Посмотри, что пишет чат.
- **Кик «Outdated client» или «Версия клиента не подходит»**: укажи в поле «Версия» версию сервера или очисти поле (авто).
- **exe долго открывается**: portable-версия при каждом запуске распаковывается во временную папку. Быстрее запускать `dist\win-unpacked\MineBlaze Bot Panel.exe` (копировать всю папку `win-unpacked` целиком).
- **Windows SmartScreen предупреждает при запуске exe**: файл не подписан сертификатом. Нажми «Подробнее», затем «Выполнить в любом случае».
- **Ошибка при сборке про символические ссылки (symbolic link)**: запусти `build-exe.bat` от имени администратора или включи «Режим разработчика» в настройках Windows.
- **Ошибка сборки EBUSY**: закрой запущенную панель и собери ещё раз. Если панель не запущена, файл мог держать антивирус или Проводник с открытой папкой `dist`: закрой окно Проводника, удали `dist\win-unpacked` и собери снова.
- **Ошибка сборки «The specified electronDist does not exist»**: не скачался сам Electron. `build-exe.bat` теперь докачивает его сам; вручную: `node node_modules/electron/install.js`.
- **Экран бота серый или видна только часть мира**: подожди несколько секунд, пока загрузятся чанки, или нажми F5 в окне экрана. Если в консоли есть строки «Экран бота: …», в них написана причина.
- **F12 в окне приложения** открывает инструменты разработчика, там видны внутренние ошибки интерфейса.

Перед использованием на сервере проверь его правила: на многих серверах боты и автоматическая добыча запрещены.
