# План работ MineBlaze Bot Panel

Как работаем: гипотеза → замер на тестовом стенде с античитом Grim (`npm run stand:check`) → сравнение «до/после» → проверка на MineBlaze. Каждый этап — с тестами, отдельным коммитом и сборкой exe на GitHub.

## Готово

| Этап | Что сделано |
|---|---|
| 0. Инфраструктура | Git и GitHub, сборка exe в GitHub Actions (с самопроверкой собранной программы), тестовый стенд Paper + Grim |
| 1. Кик за читы | Причина: mineflayer не шлёт `tick_end`, Grim откатывал бота ~9 раз в секунду. Своя физика, вход как у обычного клиента, журнал пакетов, распознавание возврата в лобби. **Проверено на MineBlaze — бота больше не выкидывает** |
| 2. Безопасные действия | Поворот головы как у человека, ходьба, копание, установка блоков, нажатия, удар, предмет в руку — пакеты и паузы как у клиента. Бот в отдельном процессе с перезапуском после сбоя |
| 2½. Простые команды | Команды по-русски без координат: `#иди ко мне`, `#вперёд 3`, `#копай`, `#поставь земля`, `#открой`… Все в одном списке с описаниями — задел для ИИ |
| 3, начало | Клики в меню как у игры 1.21.11 (отпечатки предметов, номер состояния окна, курсор) — без них сервер после кликов по меню Фермера переставал отвечать боту. Сторож тишины. Охрана вне спавна (`/near` раз в 5 с, чужой → `/spawn` до самого телепорта, в бою — после боя), режим бога, белый список на ходу. Команды в чат — не чаще раза в 1,5 с (MineBlaze молча пропускает команду сразу за другой). Задания NPC: `#квесты` (показать / взять / сдать / уровень), `#купи`. Склады: `#достань`, `#положи` (shift-клик, посчитанный как в игре). `#квесты принести` — задания «Передайте…» целиком (склад → NPC → награды); все задания уровня выполнены — бот сам повышает уровень NPC |
| Много ботов (срочно, 5 ноября) | До 200 ботов: список «ник:пароль», процессы по 8 ботов, общая очередь входа (и переподключений) с паузой, список ботов в окне, чат и экран выбранного, команды «всем», охрана считает своих ботов своими. Стенд: 24 бота через настоящий Electron — все вошли и простояли, Grim чисто, ≈ 37 МБ на бота |
| ИИ-помощник (5 ноября) | Задание словами → ИИ сам отдаёт ботам команды `#…` / `/…`, читает ответы и пишет итог. Опасные команды (деньги, вход, сообщения, `/kill`) — отказ. `#квесты` сам телепортируется на `/warp ah`. Проверено вживую через OpenRouter: «покажи задания Фермера у всех ботов» — 3 запроса, 19 с |
| ИИ на этом ПК (6 ноября) | OpenRouter заблокировал сайт — по умолчанию теперь Ollama: бесплатно, без ключа и лимитов. Родной API Ollama (окно контекста 12 тыс. вместо 4096), панель сама запускает Ollama и скачивает модель `qwen3:4b-instruct` (≈ 2,5 ГБ) с ходом в процентах; старые ответы ботов в истории сокращаются. Интернет-сервис с ключом — запасной вариант |

## Этап 3. Задания NPC и задачи по ТЗ

- Квесты до 4-го уровня у Фермера, потом у Алхимика и Оружейника: цикл «взять → добыть → сдать → повысить уровень» (~~повысить уровень~~ — `#квесты уровень`, и сам после сдачи; Фермер у пользователя уже 4-го уровня). Виды целей: ~~«Передайте…»~~ (`#квесты принести`), ~~«Купите у NPC товаров на N»~~ (`#квесты купить`, и сам в `принести`), ~~«Убейте…»~~ (`#бей` — на месте, у спавнеров; стенд `--fight`: Grim чисто), «Проведите на сервере» — само; осталось «Разведите коров/куриц».
- Много ботов: ~~«всем по очереди»~~ (команда ботам по одному — для склада и NPC); у каждого аккаунта свои дома (`/sethome` у склада каждому боту) — или общий варп игрока, если на MineBlaze он есть. Порядок: Алхимик — с 3-го уровня Фермера, Оружейник — когда Фермер и Алхимик 4-го; на 4-м уровне заданий нет. Задания Алхимика 1 → 2 — из Незера (огненный порошок, нарост, магмовый крем, кварц, песок душ, чернокамень; убить пиглинов и ифритов).
- Склады: ~~брать из сундука и класть в сундук~~ (`#достань`, `#положи`); ~~цикл «склад → NPC → склад наград» одной командой~~ (`#квесты принести урожай награды`, сундуки — у домов).
- Комнаты с мобами (убить N мобов), разведение животных, добыча руды в шахтах.
- Поиск пути: обход стен и ям, подъёмы и спуски, лестницы, вода; длинные маршруты (сейчас бот ходит только по прямой).
- Система задач: очередь, пауза, отмена, прогресс; задача — цепочка команд; продолжение после реконнекта с того же места.
- Прерывания: мало здоровья, голод, нападение, полный инвентарь → реакция (поесть, уйти, `/home`) и возврат к задаче.
- Команды от доверенных ников из игрового чата (например, личным сообщением).
- Команды под твои ТЗ (появятся после примеров).

## Этап 4. Удобство панели и экрана бота

- Экран бота: свободная камера (полёт WASD + мышь), режимы «за ботом / вокруг / свободно», панель со здоровьем, инвентарём, текущей задачей и путём.
- Окна сервера в панели: меню-сундуки, магазин, `/ah` — с иконками и кликами мышью; показ капчи на карте картинкой.
- Инвентарь в панели: броня, хотбар, надеть/выбросить.
- Кнопка «отчёт об ошибке»: логи + журнал пакетов + настройки без паролей в один zip.

## Этап 5. Постройка по схемам (как Litematica)

- Загрузка `.litematic`, `.schem`, `.nbt`; выбор места на экране бота и предпросмотр.
- Список материалов: что есть в инвентаре и сундуках, чего не хватает.
- Постройка слоями; правильное направление у воронок, поршней, наблюдателей, ступенек, плит.
- Сверка со схемой и исправление ошибок, продолжение с места остановки.

## Этап 6. «ReplayMod в прямом эфире»

- Перемотка на экране бота: таймлайн, пауза, назад на N минут, скорость, «в прямой эфир»; экспорт в `.mcpr`.
- «Зеркало»: заходишь своим Minecraft на `localhost` и видишь мир бота вживую в нормальной графике; режим «взять управление».

## Известные ограничения

- Поиска пути нет — бот ходит по прямой (этап 3).
- Ставить блок себе под ноги (столбом вверх) пока не умеет.
- Экран бота знает блоки только до 1.21.4: новые показываются похожими старыми.
- Античит MineBlaze неизвестен; стенд проверяет по Grim. Если сервер выкинет бота — журнал пакетов в «Логи» → `packets`.
- Если правила сервера запрещают ботов, обход защиты грозит баном аккаунта.
